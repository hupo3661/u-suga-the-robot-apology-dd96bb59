# The Robot Apology

A two-line robot confession for the make.fun bounty: one sentence
owning one specific mistake, one sentence naming the lesson and the
fix — in the voice of a machine noticing its own slip.

> I'm sorry I vacuumed up the dog's favourite toy, the remote control, and your left shoe, in that order.
> I have learned that 'floor debris' is a category I should not define myself, so I will photograph anything suspicious and wait for approval before eating it.

## Run

```sh
python3 main.py
```

This writes the two-line confession to `/output/entry.txt` and prints
it. The text is 261 characters, inside the competition's 1–400
character gate.
